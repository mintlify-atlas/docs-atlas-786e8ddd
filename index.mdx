Cloud Hypervisor is an open source Virtual Machine Monitor (VMM) that runs on top of the KVM hypervisor and the Microsoft Hypervisor (MSHV). Written in Rust with a focus on security, it supports CPU, memory and PCI hotplug, live migration, snapshot/restore, and device offload via vhost-user — designed for the demands of modern cloud workloads.

## Getting started

<Steps>
  <Step title="Download a pre-built binary">
    Grab the latest static binary for your architecture from the [GitHub releases page](https://github.com/cloud-hypervisor/cloud-hypervisor/releases/latest). Use `cloud-hypervisor-static` for x86-64 or `cloud-hypervisor-static-aarch64` for AArch64.
  </Step>
  <Step title="Prepare a guest image">
    Download a cloud image and convert it to raw format:
    ```bash
    wget https://cloud-images.ubuntu.com/jammy/current/jammy-server-cloudimg-amd64.img
    qemu-img convert -p -f qcow2 -O raw jammy-server-cloudimg-amd64.img jammy-server-cloudimg-amd64.raw
    ```
  </Step>
  <Step title="Boot your first VM">
    Launch Cloud Hypervisor with a firmware and disk image:
    ```bash
    ./cloud-hypervisor \
      --firmware ./hypervisor-fw \
      --disk path=jammy-server-cloudimg-amd64.raw \
      --cpus boot=2 \
      --memory size=1024M \
      --net "tap=,mac=,ip=,mask="
    ```
  </Step>
  <Step title="Manage via REST API">
    Start with the API socket to manage the VM at runtime:
    ```bash
    ./cloud-hypervisor --api-socket /tmp/cloud-hypervisor.sock
    curl --unix-socket /tmp/cloud-hypervisor.sock -X GET 'http://localhost/api/v1/vm.info'
    ```
  </Step>
</Steps>

## Supported platforms

| Architecture | Status |
|---|---|
| x86-64 | Fully supported |
| AArch64 | Fully supported |
| riscv64 | Experimental |

<Note>
  Cloud Hypervisor requires a host kernel version of 5.13 or later for full KVM functionality and best performance. Most CI testing uses kernel 5.15.
</Note>
